## 一、选股规则（金字塔）

### 1.1 硬性财务门槛（全部满足才进入评分）

| 指标 | 阈值 | 判定逻辑 |
|------|------|----------|
| **ROE** | ≥ 10% 合格；≥20% 稳健；≥35% 优秀 | 取近 5 年年报；5 年平稳或上升优先 |
| **毛利率** | ≥ 20% | 近 5 年稳定（波动率 cv < 0.20 为稳） |
| **净利率** | ≥ 10% | 或 ≥9% 且趋势向上；或 ROE≥20% 且净利率≥20% |
| **现金/总资产** | 5 年均值 ≥ 10% | 最好 ≥25% |
| **负债率** | 稳定，不飙升 | 剔除「上升趋势且波动大」 |
| **EPS** | 整体增长 | 允许一次 >10% 下滑；整体增长或均值正增长 |

> 参考官网阈值：ROE ≥10% 合格 / ≥20% 稳健 / ≥35% 优秀；净利率 ≥10% 合格 / ≥20% 优秀；现金占比 5 年均 ≥10% / ≥25% 安全。

### 1.2 综合评分（0–1000，官网金字塔权重精神）

| 维度 | 权重 | 打分 |
|------|------|------|
| ROE | 30% | 最新 ROE / 35% × 1000；上升 ×1.15，稳定 ×1.05 |
| 净利率 | 20% | 最新净利率 / 20% × 1000；上升 ×1.10 |
| 毛利率 | 20% | 最新毛利率 / 30% × 1000；上升 ×1.05 |
| 现金占比 | 15% | 5 年均现金比 / 25% × 1000 |
| 负债稳定 | 10% | 稳定 800；下降 1000；上升按波动扣分 |
| EPS 增长 | 5% | 500 + 累计增速 × 10（封顶 1000） |

### 1.3 金字塔行业过滤（铁律）

- **申万三级行业**（`AShareSWNIndustriesClass`，共 337 个行业）内比较，不跨行业。
- 每年 4 月 30 日，基于上一年年报：
  1. 全部股票算分
  2. 按行业分组，行业内按综合评分从高到低排序
  3. **只保留行业内评分前 10%**（至少 1 只）进入候选池
- 效果：3540 只 → 每年 118~158 只。

### 1.4 v9-robust 绝对质量线（评分前强制）

在 v8 基础质量全部合格后，再同时要求：

```text
近5年最低ROE >= 8%
近5年平均ROE >= 12%
近5年ROE线性斜率 >= -3个百分点/年
近5年最高资产负债率 <= 70%
```

先过这四条，再在申万三级行业内取综合评分前10%。不要增加现金流、自由现金流、PE/PB分位硬闸；2010–2016消融显示这些规则严重错杀趋势赢家。完整证据读取 `${HOLDLE_ROOT:-$HOME/code/holdle}/03_投资体系/HOLDLE_v9a-core_完整规则.md`。

## 二、买入规则（状态A择时）

### 2.1 月K状态A

月线 MACD 三要素**全部**在 0 轴上方：`DIF ≥ 0 且 DEA ≥ 0 且 MACD 柱 ≥ 0`。

### 2.2 有效开窗事件与四道硬闸

开窗事件只认两种：

- **场景一·绿转红**：月K柱由负转正。
- **场景二·矮转高**：已经处于状态A，红柱先缩短、随后第一次重新变高。连续变高的第二根及以后不重复开窗。

事件出现后还必须同时通过：

1. 月K状态A：`DIF ≥ 0 且 DEA ≥ 0 且 MACD柱 ≥ 0`。
2. 贴0轴检查：`MACD柱 ≥ 0.5`；小于0.5降级，不参与。
3. 统一硬闸：`MACD柱 ≤ DEA`；柱高于DEA，禁止写入场。
4. 至少有30根完整月K；不足30个月的次新股不判开窗。

官网课程只定性要求“月K上升趋势”，没有给出固定回看根数；最新三案例的可执行检查表也没有“最近3根高低点严格抬高”这一硬指标。因此不得再自行增加三根月K过滤。

### 2.3 窗口状态机

- 同一存活窗口只开一次，后续连续红柱变高不重复生成新窗口。
- 未入场时，开窗次月月柱若比开窗月变矮，则于次月末关闭本窗口。
- 未入场时，只要DIF、DEA或柱任一跌破0轴，状态A失效，窗口清零。
- 窗口关闭后，后续首次“矮转高”可以作为续命窗重新检查全部硬闸。
- 已入场后不再用月K柱变矮或状态A失效卖出，持仓只执行第三章卖出规则。

### 2.4 次月检查日K并找买点

月K开窗确认后，**到下个月**检查日K：

```
月K有效开窗（事件 + 四道硬闸）
    ↓
下个月检查日K
    ↓
次月首日已经是绿柱？
    ├── 是 → 回溯这段连续绿柱在开窗月内的起点
    └── 否 → 等次月首次红转绿
              ↓
从开窗月第1个交易日到绿柱起点取最高价 = 入场参考价
              ↓
盘中最高价严格突破参考价？
    ├── 是 → 买入（不等收盘确认）
    │         ↓
    │   以参考价作为当前回测成本价
    └── 绿柱确认后60个交易日仍未突破 → 入场失效
```

**关键参数：**
- 日K绿柱 = MACD柱 `< 0`；次月首日若已处于连续绿柱段，必须回溯该段起点，不能漏掉。
- 参考价区间 = 开窗月第1个交易日（含）至绿柱起点（含）。
- 突破窗口 = 绿柱确认后的60个交易日，而不是从次月首日开始计时。
- 突破条件 = 日内最高价严格 `>` 参考价；等于不算突破，不等待收盘确认。
- 错过状态A初期（股价已大涨）→ **不追高**，等下一个状态A

### 2.5 仓位约束

- 每只股票单仓位；持仓期间跳过新窗口。
- 同一股票持仓期间不重复开仓；卖出后只有出现新的有效窗口才可再次入场。

## 三、卖出规则（固定 -40% 强制止损 + 官网周K双确认止盈）

### 3.1 固定成本 -40% 强制止损（用户最终口径）

| 条件 | 止损线 | 执行方式 |
|------|--------|----------|
| 尚未切换到周K盈利保护 | 入场价 × 0.60（**-40%**） | 日内最低价触线即按止损线强制退出 |

> 固定止损不随峰值上移，不使用官网原版的 -10%/保本阶梯，也不等待周收盘确认。

### 3.2 周K低点动态止盈（官网实际案例口径）

1. **第一根周K绿柱** → 确认本周期前高（绿柱前最近高点）
2. **突破前高** → 计算有效低点（前高日期 ~ 本次突破高点之间的最低价）
3. **有效低点 > 入场价** → 切换为周K盈利保护模式，固定 -40% 止损停用
4. **安全线 = 最新有效低点，只上不下**（后续突破再抬高）
5. 同一周必须同时满足**周最低价 < 安全线**且**周收盘价 < 安全线** → 按该周收盘价卖出；仅盘中跌破但收盘收回时继续持有

东鹏饮料完整回归：成本240.90，安全线285.6298，2026-04-03周收盘281.4949确认退出，收益16.8513%。药明尚无实际出场；美的2017窗口未公开逐周中间状态，禁止猜隐藏参数强行拟合。

### 3.3 出场信号总结

| 出场方式 | 触发条件 | 意义 |
|----------|----------|------|
| 固定硬止损 | 日内最低价触及成本 -40% | 控亏：单笔最大规则亏损固定为 -40% |
| 周K低点 | 周最低价与周收盘均跌破安全线 | 止盈：趋势走坏且周末确认才走 |

## 十、与官网的差异（明确标注）

| 项 | 官网 | 本技能 `v9-robust` |
|----|------|-----------|
| ROE | ≥10% 合格，行业内排名前 10% | 增加5年ROE/负债绝对质量线后再做行业前10% |
| 金字塔 | 行业前 10% 排名 | 一致（申万三级行业） |
| 买入 | 开窗事件 + 四道硬闸 + 次月日K绿柱 + 盘中突破 | 一致；三 A 股案例买入日期与参考价设回归测试 |
| 止损 | 三阶止损（-20/-10/保本） | 用户覆盖为固定成本 -40% 强制止损 |
| 止盈 | 通用规则写“跌破周K有效低点”；东鹏实际案例明确周收盘确认 | 采用东鹏实际案例：周最低价+周收盘双确认 |
| 组合 | 未明确 | 10万 / 1万 / 10只（用户定制） |
| 月K趋势 | 定性要求上升，未规定固定回看根数 | 不再擅加“最近3根严格抬高”硬闸 |
