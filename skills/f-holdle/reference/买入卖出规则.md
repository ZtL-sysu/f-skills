# 买入与卖出规则明细

## 一、买入（择时篇）

### 1.1 月K状态A

状态A = 月线 MACD 的 **DIF、DEA、MACD 柱三者全部 ≥ 0（0 轴上方）**。

只要有一条线或柱子不在 0 轴上方，就不是状态A。**不用**金叉死叉、背离、多头空头排列这些复杂概念。

### 1.2 开窗事件与硬闸

- **绿转红**：月K柱由负转正。
- **矮转高**：状态A内红柱先变矮，随后第一根重新变高；连续变高不重复开窗。
- **贴0轴检查**：柱必须 `≥0.5`。
- **统一硬闸**：柱必须 `≤DEA`。
- **样本期**：至少30根完整月K。

课程只定性写“月K上升趋势”，未给固定根数；三案例的执行检查表不含“最近3根高低点严格抬高”，因此不把该自定义公式作为硬闸。

### 1.3 窗口状态

- 同一窗口只开一次；次月柱变矮则未入场窗口关闭。
- 状态A失效则未入场窗口清零。
- 关闭后下一次首次矮转高可作为续命窗重新检查。
- 买入后月K变化不作为卖出信号。

### 1.4 入场流程

```
有效开窗（事件 + 状态A + 柱≥0.5 + 柱≤DEA + 30月样本）
    ↓
到次月检查日K
    ↓
次月首日已在绿柱段 → 回溯该段在开窗月内的起点
次月首日为红柱       → 等次月首次红转绿
    ↓
开窗月首个交易日 ~ 绿柱起点的最高价 = 入场参考价
    ↓
绿柱后60个交易日内，盘中最高价严格 > 参考价 → 买入
    ↓
60个交易日不突破 → 入场失效
```

### 1.5 纪律铁律

- **错过初期不追高**：状态A初期窗口错过、股价已大涨，不买，等下一个
- **入场失效不死扛**：从绿柱确认后计60个交易日，仍不突破就放弃
- 状态A是"时机窗口"，不是"随时可用的优惠券"

## 二、卖出

### 2.1 固定成本 -40% 强制止损（用户最终口径）

| 条件 | 止损线 | 执行 |
|------|--------|------|
| 未切换到周K盈利保护 | 入场价 × 0.60（-40%） | 日K最低价触线即按止损线强制退出 |

固定止损不随峰值上移，不使用 -10% 或保本式阶梯，也不等待周收盘确认。

> 官网原始三阶阈值为 -20% / -10% / 保本；用户明确覆盖为单一固定 -40% 强制止损。

### 2.2 周K低点动态止盈（官网实际案例口径）

1. **第一根周K绿柱** → 确认本周期前高（最近高点）
2. **突破前高** → 计算有效低点 = 前高日期 ~ 本次突破之间的最低价
3. **有效低点 > 入场价** → 切换为周K盈利保护模式，固定止损停用
4. **安全线 = 最新有效低点，只上不下**（后续突破有效低点再抬高）
5. 同一周 **最低价 < 安全线且周收盘价 < 安全线** → 按该周收盘价卖出；盘中跌破但收盘收回不卖

### 2.3 出场对比

| 出场方式 | 触发 | 角色 |
|----------|------|------|
| 固定 -40% 止损 | 日内最低价触及止损线 | 强制控制亏损下限 |
| 周K低点 | 周最低价与周收盘均跌破安全线 | 保住趋势利润 |

> 当前模式为 `website_profit`：固定-40%止损 + 官网双确认止盈。`v8_holdle40_web_buy_low_only` 是最低价单确认的历史基线，不得引用为当前规则。

## 三、组合管理（10万/10仓）

- 总资金 100,000；每仓固定 10,000；最多 10 仓
- 候选信号超出容量 → 按选股综合评分从高到低择优
- 持仓退出释放资金后才能开新仓；同股票不重复持仓
- 事件驱动：同一买入日先处理到期持仓释放资金，再按评分开仓
